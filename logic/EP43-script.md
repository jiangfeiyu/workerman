# EP43｜跨部门天天开对齐会扯皮？用“康威定律”重划职责边界

> **本集学习目标**：在项目总需要 5 个部门拉长会对齐时，学会用组织设计里的 **康威定律（Conway's Law）** 判断是不是团队切错了边界——明白**“用清晰接口边界消灭扯皮”比“天天开会求沟通”高级十倍**。

---

## 一、 自己先学懂（1 分钟内核 + 职场自测）

### 核心概念
软件和组织架构界有一条神准的 **康威定律（Conway's Law）**：**“一个组织怎么划分部门和汇报线，最终做出来的产品和业务流程就会长成什么样子。”**
如果你发现一个小需求每次都要 **前端组 ＋ 后端组 ＋ 数据组 ＋ 运营组 ＋ 审批组** 开 5 场拉通会才能推进，**根本不是大家沟通情商低，而是你按“工种竖井”切分了团队，把本该在一个脑子里闭环的完整业务硬生生撕成了 5 段！**
**破局关键**：按 **“完整端到端业务价值”** 重组小闭环，再用标准化的 **接口契约（边界清单）** 替代无休止的群里撕逼！

### 随堂自测
> 做一个“客户退款极速到账”小功能，却因为退款页面归 C 端组、账单校验归财务组、资金打款归支付组，三个部门互踢皮球拖了半年。最治本的改法是什么？

**答案解析**：**成立围绕“退款闭环结果”的跨职能小分队（或者只由一个负责人统筹完整目标），其余两组只暴露标准清晰的 API / 财务核对接口！** 用结构边界代替跨部门踢皮球。

## 二、 4 段式分镜与口播逐字稿

### 场景 1｜01 无尽对齐会扯皮现场（`SceneHook`）
- **产品同学**：我就想改个订单详情页小字段，怎么拉了设计、前端、中台、财务五个组开了三小时对齐会还没定下来？
- **研发同事**：因为中台只管按自己 KPI 改公共表，出事故归前端背锅、赔钱归财务管，谁敢轻易点头放行啊！

**口播字幕**：
1. 大公司最消耗灵魂的一句话就是：“走，拉五个组再开个对齐会！”
2. 本来两天能干完的小需求，五个部门扯皮半个月还没动工！
3. 真的是这帮同事不配合、情商低吗？不是！是你的组织架构切错了！

### 场景 2｜02 图解康威定律与接口边界（`SceneOrgMechanism` `mode="conway-boundary"`）
**口播字幕**：
1. 组织怎么切分，流程就会有多卡顿，这就是大名鼎鼎的“康威定律”。
2. 左边是按工种硬切出来的“部门竖井”：前端只管画图、后端只管接口、财务只管对账，一个完整业务被迫穿过五堵墙，每次交接必扯皮；
3. 真正高效的组织长在右边：按“端到端完整交付”组成闭环小组，把所有强相关的兵配齐在一条船上；
4. 实在需要跨组配合的地方，定死“黑盒接口契约”——你只需按标准交出数据格式，我不插手你内部怎么写，彻底告别无意义的群里撕逼！

### 场景 3｜03 协作架构前后对比（`SceneCompare`）
- ❌ **竖井拼接 ＋ 靠开会对齐**：“每个工种单独成组、各背各的 KPI，跨部门配合全靠开拉通会互求帮忙！”（需求越大沟通成本指数级爆炸）
- ✅ **闭环小队 ＋ 标准接口契约**：“围绕业务闭环配齐前后端与运营共担指标，组间只靠白纸黑字的接口契约交接，零废话对齐！”

**口播字幕**：
1. 看对比：左边把一条完整的链条砍成五节，然后指望开会用胶水粘起来；
2. 右边把紧耦合的环节装进一个闭环团队，组外定死干净的接口规范，效率直接起飞！

### 场景 4｜04 3 秒随堂小测 & 口诀（`SceneQuiz`）
- **题目**：两个团队天天在群里吵“这行异常数据到底该谁先洗干净”，一吵就是一小时。最缺什么？
- **答案**：**缺一份白纸黑字的“上下游数据接口契约（Schema 边界约定）”**！写清入参出参规范和兜底归属，争吵瞬间消失。
- **金句口诀**：**扯皮多半架构错，闭环组队定接口！**

**口播字幕**：
1. 三秒自测：上下游两组天天吵“脏数据到底该谁清洗”，最缺什么才能一劳永逸？
2. 对！一份写死谁产谁洗的标准接口契约，把灰色地带划清楚就不再吵了！
3. 记住口诀：扯皮多半架构错，闭环组队定接口！
