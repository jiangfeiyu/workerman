# EP62｜一个 AI 又写方案又做质检为什么总放水？多智能体三权分立

> **本集学习目标**：看懂单模型“自产自销”背后的逻辑盲区，学会用 **多智能体角色隔离（生成者 Maker + 校验者 Checker + 红队 Auditor）** 搭建三权分立流水线，把隐蔽漏洞在内部提前拦截。

---

## 一、 自己先学懂（1 分钟内核 + 职场自测）

### 核心概念
很多人让同一个对话窗口里的 AI 先写一份方案，接着直接问它：“你觉得这份方案有啥问题吗？”——结果 AI 大概率客客气气回你：“总体非常扎实，仅有 2 个微不足道的小建议”。
为什么同一个 AI 会给自己放水？因为**在同一个上下文里，模型会顺着自己刚写出的假设惯性（上下文自洽偏误）继续圆谎**！
解决办法就是**多智能体角色隔离（三权分立）**：
1. **生成者（Maker）**：只负责结合业务前提拼命产出方案初稿；
2. **校验者（Checker）**：**清空对话上下文**，只拿《验收清单》和《客观事实源》冷酷逐条打勾核验，不负责改写、只负责打回；
3. **红队审查官（Auditor）**：专门拿着行业反例和最坏场景往死里攻击，必须找出至少 2 个致命风险才能通过。

### 随堂自测
> 团队用 AI 写完一份外发合同条款后，在同一个聊天框里顺手问 AI：“帮我检查一下这份合同有没有漏洞。”为什么这步检查几乎无效？

**答案解析**：因为**生成与审查混在了同一个上下文里**！AI 受到前面自己刚写文字的锚定惯性影响，极易“视而不见”。必须**新开独立会话（隔离上下文）**，只喂给它“作为对方挑刺法务，找出 3 个让我方吃亏的条款”！

## 二、 4 段式分镜与口播逐字稿

### 场景 1｜01 AI 自问自答放水现场（`SceneHook`）
- **同事**：我刚在同一个对话里让 AI 写完方案，又让它自己检查一遍，它说“逻辑满分没毛病”！
- **法务**：没毛病？第三页引用了一条根本不存在的法规，第五页预算加起来多了二十万，它自己怎么没查出来？

**口播字幕**：
1. 用 AI 审材料最常见的一个低级失误，叫“让同一个人既当运动员又当裁判员”！
2. 你在同一个窗口让它写完方案，顺嘴问一句“帮我看看有没有错”，它大概率夸自己逻辑完美！
3. 因为模型会顺着刚才自己编的思路继续圆谎——要抓出真漏洞，必须把角色彻底隔离开！

### 场景 2｜02 图解多智能体三权分立（`SceneAgentFlow` `mode="multi-agent-separation"`）
**口播字幕**：
1. 搭建靠谱的多智能体流水线，核心秘诀就四个字：三权分立。
2. 第一号角色叫“生成者”：只负责根据前提拼命产出初稿；
3. 第二号角色叫“校验者”：彻底清空刚才的聊天记忆，只拿事实来源和验收清单冷酷打勾，缺一条直接打回；
4. 第三号角色叫“红队审查官”：专门扮演挑刺老板和敌对法务，不找出三个硬伤不准下班！三方互不包庇，错误率直接砍掉九成！

### 场景 3｜03 智能体审查对比（`SceneCompare`）
- ❌ **同一窗口自产自销**：“在刚才那个写方案的对话框里，继续输入：请帮我检查一下有没有遗漏或错误。”（被历史上下文带偏，互相放水）
- ✅ **隔离上下文三权分立**：“新开无记忆独立窗口，只传入方案正文 + 验收红线清单，命令红队 Agent 逐条挑刺打回。”（漏洞无处遁形）

**口播字幕**：
1. 看对比：左边看似问了一句检查，其实被同一段对话记忆锁死了视角，等于左手审右手；
2. 右边通过清空上下文做角色隔离，让冷酷校验官只认标准不认人，隐藏漏洞一下全被揪了出来！

### 场景 4｜04 3 秒随堂小测 & 口诀（`SceneQuiz`）
- **题目**：如果只有一个大模型接口，怎么低成本实现“生成者 + 校验者”隔离，防止自己给自己放水？
- **答案**：**发起一次全新的独立 API 调用（不带入生成的历史聊天记录）**，只把最终产出文本 + 独立验收规则发过去审查！
- **金句口诀**：**同框自审必放水，生成校验要分家；清空记忆换视角，三权分立抓硬伤！**

**口播字幕**：
1. 三秒自测：只用同一个模型，怎么低成本做到“不给自己放水”？
2. 对！新开一条完全不带历史聊天的独立会话，只把成品和硬标准喂给它冷酷复核！
3. 记住口诀：同框自审必放水，生成校验要分家；清空记忆换视角，三权分立抓硬伤！
