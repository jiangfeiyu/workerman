# EP33｜越砸钱越拉不动？看懂“增强回路”与“调节回路”

> **本集学习目标**：在做增长规划和业务诊断时，不再只看单一原因，而是用系统动力学的 **增强回路（R：滚雪球飞轮）与调节回路（B：隐形刹车上限）** 找到真正的卡点与撬动点。

---

## 一、 自己先学懂（1 分钟内核 + 职场自测）

### 核心概念
很多业务“开头越做越快，突然某天怎么投流都涨不动了”。系统里永远同时藏着两股力量：
1. **增强回路（R · Reinforcing Loop）**：A 推高 B，B 又反过来拉高 A（如：好内容吸引新用户 ➔ 产生更多评价和推荐 ➔ 吸引更多新用户）。它是增长飞轮，但坏事也能滚雪球（如“体验差 ➔ 差评多 ➔ 没流量”）。
2. **调节回路（B · Balancing Loop）**：任何系统都有刹车和天花板（如：用户一多 ➔ 客服排队、服务器卡顿 ➔ 退货和流失升高 ➔ 增长被硬生生拉平）。**撞上调节回路时，继续猛踩增强油门只会白白烧钱！**

### 随堂自测
> 某 SaaS 产品花大价钱买广告获客，新客注册暴涨 3 倍，但三个月后总活跃人数几乎没变，钱全打了水漂。从系统回路来看，负责人漏看了什么？

**答案解析**：**他只往“增强回路（买量拉新）”踩油门，却没看见底下的“调节回路（新手引导太难导致次周流失 90%）”！** 必须先拆掉卡住体验的调节刹车，飞轮才能真正转起来。

## 二、 4 段式分镜与口播逐字稿

### 场景 1｜01 砸钱失灵现场（`SceneHook`）
- **增长同学**：老板，上个月投十万广告效果炸裂，这月我把预算翻了五倍，转化怎么纹丝不动啊？
- **客服主管**：因为新用户涌进来没人教怎么用，工单排了三千条，老用户都被卡退订了！

**口播字幕**：
1. 做业务最崩溃的一幕莫过于此：
2. 上个月买量翻倍狂飙，这个月把预算加到五倍，总业绩居然一动不动！
3. 为什么同一套成功打法突然失灵？因为你只看见了加油的飞轮，没看见暗处的刹车！

### 场景 2｜02 图解增强回路与调节回路（`SceneSystemLoop` `mode="reinforcing-balancing"`）
**口播字幕**：
1. 任何业务系统里，都藏着增强和调节这两套循环。
2. 左边叫增强回路：好口碑带新客，新客再晒好评价，越转越快像滚雪球；
3. 可只要雪球一滚大，右边的调节回路必然启动：客服排队、服务器变卡、履约跟不上，逼着老客悄悄流失；
4. 撞到天花板后还死磕买量，就像一边踩油门一边拉手刹！先解开交付瓶颈这个刹车，飞轮才能继续飞！

### 场景 3｜03 增长策略前后对比（`SceneCompare`）
- ❌ **死磕油门硬买量**：“转化卡住了？肯定是推广声音不够响，下月预算再加倍冲！”（烧钱养出一堆秒退用户）
- ✅ **先松手刹再推飞轮**：“注册暴涨但次留卡死在调节环！先停掉一半买量，用两周打通新人 5 分钟上手体验，再放量。”

**口播字幕**：
1. 看对比：左边在刹车拉死的情况下猛砸预算，全在填漏水的木桶；
2. 右边先找出限制上限的调节回路把漏洞堵上，花原来一半的推广费，净留存反而翻倍！

### 场景 4｜04 3 秒随堂小测 & 口诀（`SceneQuiz`）
- **题目**：一家网红餐厅每天排队 2 小时，老板为冲营收又发了大额“半价代金券”，结果月度口碑和复购反而暴跌，为什么？
- **答案**：**后厨出餐速度已撞上调节上限**！发券只会让排队更长、菜品变糙，加速触发负向雪球。
- **金句口诀**：**撞墙先别猛踩油，先找暗处刹车手！**

**口播字幕**：
1. 三秒自测：餐厅都排队两小时了，再发半价大促券为什么反而拉垮复购？
2. 对！后厨出餐早就卡在调节上限了，硬拉客流只会让体验崩盘！
3. 记住口诀：撞墙先别猛踩油，先找暗处刹车手！
